AI Agent Skills & Tooling 5 stories
Agent Plugins 1.0: Package Agent Skills Once for AI Tools

Amazon, Microsoft, OpenAI and Vercel introduced Agent Plugins 1.0, a vendor-neutral open standard for packaging reusable agent capabilities — including Agent Skills and MCP servers — into a single plugin format. The spec is designed so compatible AI agent clients can load the same plugin without vendor-specific repackaging, sitting alongside MCP (standardized access to tools, resources and prompts) and Agent Skills (filesystem-based modules of domain knowledge and procedures). The pitch is that enterprises can build internal distribution and governance on top of an emerging industry standard rather than a new proprietary abstraction. Plugin portability matters because reuse across Claude Code, Codex and similar harnesses is currently the practical bottleneck.

Environments | NeMo Gym

NVIDIA's NeMo Gym docs (v0.6.0) formalize the environment abstraction for agent training and evaluation around the equation 'Agent = model + agent harness'. A dataset supplies tasks plus the privileged information needed for scoring, tasks range from single-turn QA to sandboxed agentic workflows, and runtimes such as local processes, Docker or Apptainer host them, with sandboxes providing a security boundary when the agent executes arbitrary code. The harness is what loops model calls, routes tool use, manages context and decides when a task is done — stateless inference alone isn't an agent. This turns the evaluate-improve loop into an engineering primitive rather than a prompt trick.

An Instagram post notes that Google DeepMind has described a pilot for double-blind AI evaluations, in which the model provider cannot see hidden questions in advance while the evaluator is likewise insulated from the provider.
