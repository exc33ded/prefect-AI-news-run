Top Agent Frameworks To Use in 2026: A Comparison - Splunk

Splunk's 2026 agent-framework comparison explains that frameworks exist to supply control-flow primitives — graphs, event loops or state machines — for the iterative work that simple LLM calls cannot express. It highlights a sharp divide on durability of human-in-the-loop: Microsoft Agent Framework and LangGraph treat interrupts as persistent, checkpointed events that survive process restarts or redeploys, which matters for approvals that may span days. LangGraph also treats structured output as load-bearing, since nodes return structured state that literally drives the next transition. The takeaway is to pick frameworks based on durability and control-flow needs, not feature checklists.

Energy-Proportional Allocation for Model Merging - arXiv

This paper proposes Spectral Energy-proportional Rank Allocation (SERA), a simple task-adaptive strategy for model merging that allocates ranks according to singular-value energy. The approach targets the problem of deciding how much capacity each merged component should receive. It matters because model merging is a cheap alternative to full fine-tuning, and rank allocation is a central knob controlling merged-model quality.

[PDF] The Undetected Damage of Quantization on Retrieval and ... - arXiv

This arXiv paper quantifies the 'undetected damage' of quantization on retrieval, showing that a quantized model which keeps its classification accuracy still changes 14 to 46% of its top-1 retrieval results. It further finds that aggregate ranking metrics can mask those shifts. The result matters for anyone deploying quantized embedding or retrieval models, since downstream answer quality can degrade even when standard accuracy checks pass.

RRSI: Regularized Recursive Self-Improvement of Agent ...

RRSI (Regularized Recursive Self-Improvement of agents) studies agent systems that iteratively improve themselves on task distributions. The work analyzes the cost-versus-transfer trade-off, reporting results on optimal policy tokens per trial and trajectory length using repetitive stretching games. It is relevant to growing interest in recursive self-improvement and to setting practical compute budgets for self-improving agent loops.
