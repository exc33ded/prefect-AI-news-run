Beyond Parameter Protection: Fisher-Shaped EWC for Replay-Free Continual Learning

The authors propose **Fisher‑Shaped Elastic Weight Consolidation (EWC)**, a replay‑free continual learning method that leverages the Fisher information matrix to shape regularisation strength for each parameter. Unlike classic EWC, which uses a scalar importance term, this approach assigns a full‑rank Fisher‑shaped penalty, allowing the model to retain knowledge without storing any past data. Empirical results on the Split‑CIFAR‑100 benchmark report a 7.5% improvement in average accuracy over vanilla EWC. This contribution is significant for deploying continual learning systems in privacy‑sensitive or memory‑constrained settings. The paper is listed as arXiv:2610.37145v1.
