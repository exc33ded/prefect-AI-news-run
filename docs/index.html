Weight-Space Programming Doesn't Need Transformers

The paper “Weight‑Space Programming Doesn’t Need Transformers” (arXiv:2611.22055v1, posted 17 Nov 2026) argues that the usual reliance on transformer architectures stems from their suitability for gradient‑based training on GPUs. In weight‑space programming, a large language model directly writes the target model’s weights, eliminating the need for back‑propagation. The authors demonstrate that simpler architectures can achieve comparable performance when the LLM supplies weights hand‑crafted in weight space, reducing compute overhead and model size. This challenges the prevailing assumption that transformers are indispensable for modern AI systems.
