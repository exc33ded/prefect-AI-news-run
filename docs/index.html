Prompting & Agentic Workflow Techniques 5 stories
Harness engineering vs loop engineering | Data Science Dojo

The article distinguishes harness engineering from loop engineering, arguing prompt engineering has the lowest ceiling of the four. Loop engineering was named by Addy Osmani in June 2026 and means replacing yourself as the person who prompts the agent with a system that does it. Its ancestor is Geoffrey Huntley's Ralph Wiggum technique, a bash loop that reruns an agent until the goal is met. Context engineering became key when agent context windows became the bottleneck.
