What is an agent plugin? - Speakeasy

Speakeasy defines an agent plugin as an installable package that bundles reusable agent capabilities: typically skills (workflow instructions in a SKILL.md folder), one or more MCP servers or connectors, and harness-specific extras such as hooks, rules, commands and subagents. The stated point of the package is distribution — a team publishes one versioned plugin and people install it from a marketplace instead of wiring each server config, skill and hook file by hand. The article separates the layers cleanly: a skill is instructions, a connector/MCP server is the tool backend, a hook is a lifecycle handler, and the plugin carries any combination of them under one name and version. That vocabulary is becoming the shared language of agent tooling.
