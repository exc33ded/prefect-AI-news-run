CANDOR: Chance-Calibrated Discordance in Frozen Foundation Encoders

CANDOR measures chance-calibrated discordance in frozen foundation encoders by constructing pairs with opposite clinical labels inside one acquisition context and testing whether a vision-language representation still asserts a finding. It has an exact chance level and caps the margin any Lipschitz head can achieve on flagged cases. This is significant because it exposes shortcut learning and coordinated model failures before a classifier head is trained, making it useful for medical-imaging evaluation.
