Forward-Free LLM Depth Pruning via Weight Redundancy

Weight-Redundancy Pruning (WRP) is a forward-free method for LLM depth pruning that estimates inter-layer redundancy directly from checkpoint weights, avoiding calibration forward passes. It combines similarity between attention-output and MLP down-projection weights with projection-scale information to build an all-pairs similarity matrix for global layer selection. Across six pruning settings on three model families and nine tasks, WRP substantially outperforms forward-free magnitude pruning and stays close to activation-based methods without post-pruning recovery. The result suggests checkpoint weights alone carry useful redundancy signals for shrinking large models.

This paper tests whether pretraining familiarity survives a contamination-free hold-out for time-series foundation models such as Chronos and TimesFM.
