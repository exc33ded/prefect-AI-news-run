Loop engineering: stop prompting, start looping | Postman Blog

Postman's blog argues that the field is moving from prompt engineering to 'loop engineering': designing a system that sends prompts, runs outputs against something real, checks them against pass/fail signals, and decides whether to iterate. It warns that loops without a source of ground truth drift because the model's own guesses fill the context. The post cites Claude Code lead Boris Cherny as already using such loops instead of prompting Claude by hand.
